## The word

**doomscroll**

The whole internet in a single word. Not one app, not one site, not one
meme — the endless feed itself, and the thumb that keeps moving long past
the point of wanting to stop. Funny on its own, true of the internet as a
whole, surprising next to the obvious words, and it lands in one beat.

## How it works

`main.ts` (pure Node standard library, no dependencies, no network) writes
exactly that one word — and nothing else — to `/output/entry.txt`, after
checking it against the gate: 1 to 30 characters, a single word, not only
white space.

```sh
node main.ts
cat /output/entry.txt   # doomscroll
```
